The project analyzes the relationship between study techniques on the grades of STEM students, specifically active against passive study techniques.
The data sets used for the analysis include the top 3 most used study techniques by biology students, as well as their grades at the end of the semester.
The grades are on a scale of 1-13, the highest being the best grade (converted from the US grading system A-F; A+ = 13, F = 1).
In this project active techniques (e.g. self-testing and diagrams) are compared with passive ones (e.g. rereading and highlighting).

The data were obtained from Harvard Dataverse and were originally collected for Rodriguez et al. (2018).The datasets used are: Year_1_Studystrat &Year_2_StudyStrat.
The datasets contain survey responses of students' three most frequently used study techniques and their final course grades (scale of 1–13).
The original sample, of the 2 datasets combined, consisted of 1,326 students. After excluding 11 students who did not select exactly three techniques, the final sample contained 1,315 students.

The project was done using Python 3.14.7 in Visual Studio Code.
The packages to be installed before running the code:
* pandas
* numpy
* statsmodels
* scipy
* matplotlib

Instructions:
1. Download both datasets from Harvard Dataverse.
2. Save the datasets as Year1studystrat.csv and Year2studystrat.csv.
3. Place both CSV files in the same folder as the Python scripts.
4. Open the folder in Visual Studio Code.
5. Install the required packages.
6. Run the analysis and plotting scripts.
